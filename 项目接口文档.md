## 接口规范

### 基础信息

- **Base URL**：`http://localhost:8081`
- **认证方式**：JWT Token（Header: `Authorization: Bearer <token>`）
- **时间格式**：`yyyy-MM-dd HH:mm:ss`
- **时区**：`Asia/Shanghai`

### 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| 字段    | 类型    | 说明                 |
| ------- | ------- | -------------------- |
| code    | Integer | 状态码，200 表示成功 |
| message | String  | 提示信息             |
| data    | Object  | 响应数据（泛型）     |

### 分页响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 100,
    "page": 1,
    "pageSize": 10,
    "list": []
  }
}
```

| 字段     | 类型    | 说明     |
| -------- | ------- | -------- |
| total    | Integer | 总记录数 |
| page     | Integer | 当前页码 |
| pageSize | Integer | 每页条数 |
| list     | Array   | 数据列表 |

> **注意**：分页响应中数据列表字段名为 `list`（不是 `records`）。

### 2.10 上传头像

```
POST /api/upload/avatar
```

**请求方式**：`multipart/form-data`

**接口说明**：上传用户头像图片文件，返回头像访问 URL。前端在个人中心（`Profile.vue`）和用户管理（`UserForm.vue`）中调用此接口。

**请求头**：

| 参数          | 类型   | 必填 | 说明                             |
| ------------- | ------ | ---- | -------------------------------- |
| Authorization | String | 是   | `Bearer <token>`，JWT 认证 Token |

**请求参数**：

| 参数 | 类型 | 必填 | 说明                                                 |
| ---- | ---- | ---- | ---------------------------------------------------- |
| file | File | 是   | 要上传的头像图片文件，仅支持图片格式，大小不超过 2MB |

**前端校验规则**（el-upload `before-upload` 中已实现，后端建议同样校验）：

| 校验项   | 规则                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 文件类型 | 仅允许图片格式（`image/jpeg`、`image/png`、`image/gif`、`image/webp`、`image/bmp` 等） |
| 文件大小 | 最大 2MB（2 × 1024 × 1024 字节）                                                       |

**后端处理建议**：

1. 校验文件类型为图片格式，文件大小不超过 2MB
2. 生成唯一文件名（建议：`avatar_` + 时间戳 + 随机后缀 + 原始扩展名），避免文件名冲突
3. 将文件保存到静态资源目录（如 `static/uploads/avatars/`）
4. 返回完整的文件访问 URL
5. 用户表 `avatar` 字段存储的是 URL 字符串，由前端拿到上传返回的 URL 后，再通过 `PUT /api/system/user/profile` 或 `PUT /api/system/user/{id}` 接口更新到数据库

**前端调用方式**：

```typescript
// el-upload 组件配置（使用 http-request 通过 axios 实例统一管理）
<el-upload
  :show-file-list="false"
  :http-request="handleAvatarUpload"
  :before-upload="beforeAvatarUpload"
/>

// 上传处理函数
async function handleAvatarUpload(options: UploadRequestOptions) {
  const url = await uploadAvatar(options.file as File);
  editForm.avatar = url;
}

// API 函数（src/api/system.ts）
export function uploadAvatar(file: File): Promise<string> {
  const formData = new FormData();
  formData.append("file", file);
  return instance.post("/upload/avatar", formData, {
    headers: { "Content-Type": "multipart/form-data" },
  });
}
```

> 注：前端使用 axios 实例统一管理请求，baseURL 为 `/api`，请求自动携带 `Authorization` Token，响应自动解析 `data` 字段。

**响应格式**：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": "http://localhost:8081/static/uploads/avatars/avatar_20260906_163128_a1b2c3.jpg"
}
```

| 字段    | 类型    | 说明                                                                        |
| ------- | ------- | --------------------------------------------------------------------------- |
| code    | Integer | 状态码，200 表示成功                                                        |
| message | String  | 提示信息                                                                    |
| data    | String  | 上传后的头像文件访问 URL（前端通过 `response.data` 或 `response.url` 获取） |

**错误响应**：

| 场景             | HTTP 状态码 | code | message              |
| ---------------- | ----------- | ---- | -------------------- |
| 未登录/Token过期 | 401         | 401  | 未授权，请重新登录   |
| 未选择文件       | 400         | 400  | 请选择要上传的文件   |
| 文件类型不合法   | 400         | 400  | 仅支持图片格式文件   |
| 文件大小超限     | 400         | 400  | 图片大小不能超过 2MB |
| 服务器存储失败   | 500         | 500  | 文件上传失败         |

**调用流程**：

```
1. 用户选择头像图片
      │
      ▼
2. 前端 before-upload 校验（类型/大小）
      │
      ▼
3. POST /api/upload/avatar (multipart/form-data)
      │
      ▼
4. 后端校验 → 保存文件 → 返回 URL
      │
      ▼
5. 前端拿到 URL → PUT /api/system/user/profile 更新 avatar 字段
```

### 5.8 上传文件到知识库

```
POST /api/knowledgebase/{id}/files/upload
```

**请求方式**：`multipart/form-data`

**接口说明**：上传文件到指定知识库，自动生成带 `kb_` 前缀的唯一文件名，更新知识库文档数量。

**请求头**：

| 参数          | 类型   | 必填 | 说明                             |
| ------------- | ------ | ---- | -------------------------------- |
| Authorization | String | 是   | `Bearer <token>`，JWT 认证 Token |

**路径参数**：

| 参数 | 类型 | 必填 | 说明     |
| ---- | ---- | ---- | -------- |
| id   | Long | 是   | 知识库ID |

**请求参数**：

| 参数 | 类型 | 必填 | 说明         |
| ---- | ---- | ---- | ------------ |
| file | File | 是   | 要上传的文件 |

**后端处理逻辑**：

1. 校验知识库是否存在
2. 校验知识库的 `contentPath` 是否存在
3. 确保存储目录存在（`data/knowledgebase/{type}/{knowledgeId}/`）
4. 生成唯一文件名（格式：`kb_yyyyMMdd_HHmmss_随机后缀.扩展名`）
5. 保存文件到目标路径
6. 更新知识库的 `documentCount` 字段
7. 记录操作日志

**文件名格式**：

| 原始文件名    | 存储文件名                       |
| ------------- | -------------------------------- |
| 产品手册.pdf  | kb_20260906_170620_a1b2c3d4.pdf  |
| 技术文档.docx | kb_20260906_170620_e5f6g7h8.docx |

**文件存储路径**：

```
data/knowledgebase/
├── document/
│   └── {knowledgeId}/
│       └── kb_20260906_170620_a1b2c3d4.pdf
├── qa/
│   └── {knowledgeId}/
└── web/
    └── {knowledgeId}/
```

**响应格式**：

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "name": "产品手册.pdf",
    "size": 1024000,
    "mimeType": "application/pdf",
    "lastModified": "2026-09-06 17:06:20"
  }
}
```

| 字段         | 类型   | 说明             |
| ------------ | ------ | ---------------- |
| name         | String | 原始文件名       |
| size         | Long   | 文件大小（字节） |
| mimeType     | String | 文件 MIME 类型   |
| lastModified | String | 最后修改时间     |

**错误响应**：

| 场景             | HTTP 状态码 | code | message              |
| ---------------- | ----------- | ---- | -------------------- |
| 未登录/Token过期 | 401         | 401  | 未授权，请重新登录   |
| 知识库不存在     | 400         | 400  | 知识库不存在         |
| 内容路径不存在   | 400         | 400  | 知识库内容路径不存在 |

```

**参数**：

| 参数     | 类型   | 必填 | 说明                          |

POST /api/ai/chat
```

**请求体**：

```json
{
  "sessionId": "uuid-string",

}
```

| 参数      | 类型   | 必填 | 说明                                   |
| --------- | ------ | ---- | -------------------------------------- |

**响应示例**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "content": "你好！我是智能助手，可以帮助你查询系统数据...",
    "sessionId": "uuid-string"
  }
}
```

### 7.3 发送消息（流式 SSE）

```
POST /api/ai/chat/stream
```

**请求体**：同非流式

**响应格式**：`text/event-stream`

data: {"content":"你"}
data: {"content":"好"}
data: {"content":"！"}
data: {"sessionId":"uuid-string"}
data: [DONE]
