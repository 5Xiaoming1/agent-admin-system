# Agent 智能体管理平台 - 开发阶段文档

[TOC]

## 一、项目概览

**技术栈：** Spring Boot 3.2.5 + JDK 21 + MyBatis-Plus 3.5.9 + Redis + MySQL 8.0 + LangChain4j 1.0.1-beta6 + Knife4j 4.5.0

**核心依赖：** JWT (jjwt 0.12.7) 认证、WebFlux 流式调用、Easy RAG 知识库检索、AES 加密

**数据库表（8张）：** `setup`、`tools`、`knowledge`、`agent`、`agent_knowledge`、`knowledge_tool`、`user`、`login_log`、`operation_log`、`chat_history`

## 二、开发阶段总览

| 阶段 | 模块 | 核心内容 |
|------|------|----------|
| 阶段一 | 基础架构 | 项目初始化，集成 MyBatis-Plus、Redis、Knife4j、JWT、LangChain4j，统一 Result 封装、全局异常处理、逻辑删除 |

## 三、AI 对话架构

```
用户消息 → AIChatController
  ├── 保存用户消息到 chat_history（MySQL，会话级存储）
  ├── AssistantService (LangChain4j AiService)
  │   ├── System Prompt（system-prompt.txt）
  │   ├── Chat Memory（Redis，最近20条，TTL 2小时）
  │   ├── Content Retriever（知识库 RAG 检索）
  │   └── SystemBusinessTool（23个业务工具，覆盖全部 CRUD）
  ├── 流式返回（SSE）或非流式返回
  └── 保存 AI 回复到 chat_history
```

## 四、认证流程

```
GET /api/login/captcha → 生成验证码（Redis，5分钟）
POST /api/login → 验证码校验 + 密码校验 → JWT Token → 存入 Redis（2小时）
后续请求 → Authorization: Bearer <token> → CustomFilter → JWT 解析 → Redis 校验
```

## 六、待优化项

| 优先级 | 项目 |
|--------|------|
| 高 | 密码 BCrypt 加密、Token 用量统计、接口角色权限控制 |
| 中 | 文件上传类型限制、对话历史导出 |
| 低 | 国际化、暗黑模式、数据备份、性能监控 |

## 七、技术债务

- 密码明文存储 → 升级 BCrypt
- 部分异常处理不统一（返回 500）→ 完善全局异常处理
- 前端状态值不一致（部分 1/0，部分 active/inactive）→ 统一为字符串
